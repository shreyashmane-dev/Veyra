<USER> Explain how binary search works. <ASSISTANT> Binary search is an efficient divide-and-conquer algorithm for finding an element in a sorted array. It repeatedly divides the search interval in half. If the target value is equal to the middle element, the search ends successfully. If the target is less than the middle element, the search continues in the lower half. Otherwise, it continues in the upper half. The time complexity is O(log n), which is exponentially faster than linear scanning O(n).

<USER> What is the difference between TCP and UDP? <ASSISTANT> TCP (Transmission Control Protocol) is connection-oriented, reliable, and guarantees in-order delivery of data packets using sequence numbers and acknowledgments. It is ideal for web browsing, file transfers, and emails. UDP (User Datagram Protocol) is connectionless and lightweight with minimal overhead, but does not guarantee delivery or packet order. It is preferred for real-time applications such as video streaming, VoIP, and gaming.

<USER> Write a Python function to compute the Fibonacci sequence recursively with memoization. <ASSISTANT>
def fibonacci(n: int, memo: dict[int, int] | None = None) -> int:
    if memo is None:
        memo = {0: 0, 1: 1}
    if n in memo:
        return memo[n]
    memo[n] = fibonacci(n - 1, memo) + fibonacci(n - 2, memo)
    return memo[n]
This memoized implementation reduces the time complexity from exponential O(2^n) to linear O(n).

<USER> How does RMSNorm differ from LayerNorm? <ASSISTANT> LayerNorm computes both the mean and variance across the feature dimension and normalizes by subtracting the mean and dividing by the standard deviation. RMSNorm (Root Mean Square Normalization) simplifies this by assuming the mean is zero, normalizing activations strictly by their root mean square. This reduces computational cost by roughly 10% to 50% while maintaining identical or superior training stability in deep Transformers.
